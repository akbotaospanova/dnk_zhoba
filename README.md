# Ұлттық мәдениеттің «ДНҚ-сы»

«Қазақ жастары үшін қазақты қазақ ететін не?» ғылыми жобасының сайты.

- Оқушы: Талип Мөлдір, 9-сынып, №152 мектеп-гимназия
- Ғылыми жетекші: Шайхина К.Т.

Сайт бір `index.html` файлынан тұрады: жоба туралы, теория, мәдени код элементтері, үш деңгейлі модель, әдістеме, интерактив сауалнама, қорытынды және әдебиеттер.

## GitHub Pages
1. `index.html` пен `README.md` файлдарын репозиторийдің басты бетіне жүктеңіз (папкасыз).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. 1–2 минуттан кейін сайт `https://логин.github.io/репо-аты/` мекенжайында ашылады.
